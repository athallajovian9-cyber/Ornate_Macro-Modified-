Before you run it

These are not preferences. Get them wrong and the macro cannot work, whatever the code says: Windows scaling 100%, game at 1920×1080, Roblox Screen Shake OFF, camera Classic, Shift Lock disabled, installed from roblox.com (the Store build fails with error 0x1023), and AutoHotkey v1.1. Full list: REQUIREMENTS.

What was changed

  • It would not open at all. The Windows .ahk association hands v1 code to the v2 interpreter, which cannot parse it. All 22 launched scripts now declare #Requires AutoHotkey v1.1.
  • The dig trigger sampled the wrong pixel. CenterOfT() adjusted variables declared nowhere in the project — and in AHK v1 an undefined variable is an empty string, so the write was silently discarded.
  • The dig hold was 10× too short at low Dig Speed: the code took the first three characters of the number, turning 6690 into 669.
  • A dead donation button ran a variable that never existed.
  • A dead branch and a duplicated pixel read removed.
  • Reverted: a previous edit applied the 768-pixel offsets to 1920×1080, double-correcting a resolution the original author already handled.

Every edit with before/after: MODIFICATIONS

Testing it

Ten minutes of play, five numbered checks, and a list of what to send back — most importantly the Roblox Output window. See TESTING. Known failures are welcome; that is the point.
