Before you run it

Exact setup required

▣

These are not preferences. Get one wrong and the macro cannot work, whatever the code says.

  • Windows scaling at 100%
  • Game resolution at 1920×1080
  • Roblox Screen Shake turned off
  • Camera mode set to Classic
  • Shift Lock disabled
  • Roblox installed from roblox.com
  • AutoHotkey v1.1 installed

What changed

Five fixes. One careful reversal.

Every before & after →

The macro would not open

All 22 launched scripts now declare #Requires AutoHotkey v1.1, preventing Windows from handing v1 code to the v2 interpreter.

Dig trigger sampled the wrong pixel

CenterOfT() adjusted variables declared nowhere in the project, so AutoHotkey silently discarded the write.

Low-speed dig hold was 10× too short

The code took the first three characters of the number, turning a value such as 6690 into 669.

Dead controls removed

A donation button referenced a variable that never existed; a dead branch and duplicated pixel read were also removed.

1920×1080 regression reversed

A previous edit applied 768-pixel offsets to 1920×1080, double-correcting a resolution the original author already handled.
